### 2.3 Workflow 动作执行器

已实现 5 种动作执行器:
- **HTTP Action**: URL 请求, 支持 headers/body 模板渲染
- **DNS Action**: DNS 查询 (A/TXT/MX/NS)
- **SMTP Action**: 邮件发送
- **Webhook Action**: Webhook 调用, 支持模板渲染
- **Notify Action**: 多渠道通知 (webhook/feishu/wecom/dingtalk/slack/discord/telegram/email)

安全特性: 出站 allowlist + 超时 + 大小限制 + SSRF 防护
